# Логотипи учасників (компаній)

Сюди кладіть файли логотипів. Ім’я файлу = **назва компанії + розширення**.

## Приклади

- `EffeTex.png`
- `Delta Plus.webp`
- `Біко.jpg`

Дозволені формати: `png`, `jpg`/`jpeg`, `webp`, `svg`.

## Як підключити на сайті

У адмінці в полі URL логотипу вкажіть шлях від кореня сайту:

```text
/member-logos/EffeTex.png
```

Якщо в назві є пробіли або кирилиця — у браузері шлях кодується автоматично; у полі можна лишити як є:

```text
/member-logos/Delta Plus.png
```

або з `%20` замість пробілу.

## Примітки

- Не замінюйте файли «на місці» без зміни URL, якщо потрібен скид кешу — додайте `?v=2` до URL або змініть ім’я файлу.
- Старі seed-логотипи лежать у `public/members/` (slug-імена на кшталт `effetex.png`) — це окремий legacy-набір.
